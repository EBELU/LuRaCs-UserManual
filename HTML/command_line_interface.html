Command Line Interface (CLI)

LuRaCs is primarily operated through the GUI but it also provides a terminal-based command line interface, allowing for controlling detectors without a GUI. This may be useful if remote measurements or measurements run on a Raspberry Pi is attached to a drone. This mode shares most of the same commands as the GUI Console with the exception of visualisation tools.

This mode is started by running LuRaCs in a terminal with the –headless flag.

Command-line interface command reference.
Command Description
Table  – continued from previous page
Command Description
help Display the available commands and their descriptions.
clear Clear the console and return the application to start.
exit, quit, shutdown Exit the application.
device scan usb Scan for connected USB devices.
device scan ble Scan for nearby Bluetooth Low Energy devices.
device connect usb <device> Connect to a USB device matching the specified name.
device connect ble <device1> [device2 ...] Connect to one or more Bluetooth Low Energy devices.
device disconnect <device> Disconnect the specified device.
device disconnect all Disconnect all connected devices.
list devices Display all connected devices.
list spectra Display all loaded spectra.
list spectrogram Display all loaded spectrograms.
list rois Display all loaded regions of interest.
index spectrum Display indexed spectrum files.
index spectrogram Display indexed spectrogram files.
index roi Display indexed ROI files.
view spectrum <name> Display the specified spectrum. The spectrum can be selected by name or by its index in the loaded spectrum list.
view spectrum -n <name> Specify the spectrum to display by name.
view spectrum all Display all loaded spectra on the same plot.
view spectrum -A Display all loaded spectra on the same plot.
view spectrum -Emin <energy> Set the lower energy limit of the displayed spectrum, in keV.
view spectrum -Emax <energy> Set the upper energy limit of the displayed spectrum, in keV.
view spectrum -cps Display the spectrum as counts per second (CPS) instead of total counts.
view spectrum -log Display the spectrum using the logarithmic scaling.
view spectrum -bkgSub Display the background-subtracted spectrum, if the spectrum has a background.
view rois Display the currently loaded regions of interest.
view log Display recent application log entries.
roi <lower> <upper> Add a region of interest between the specified lower and upper bounds.
roi -c Clear all regions of interest.
spectrogram start <device> Start a spectrogram for the specified device.
spectrogram start all Start spectrograms for all connected devices.
spectrogram pause <name> Pause the specified spectrogram.
spectrogram pause all Pause all running spectrograms.
spectrogram unpause <name> Resume the specified spectrogram.
spectrogram unpause all Resume all paused spectrograms.
spectrogram load <path> Load a spectrogram from the specified file.
spectrogram unload <name> Unload the specified spectrogram.
spectrogram unload all Unload all loaded spectrograms.
-n <name> Specify a custom name when starting a spectrogram.
-i <seconds> Set the spectrogram save interval. Default: 1 second.
-c <count> Set the number of spectra to concatenate before saving. Default: 1.
map url <https-URL> Load an online map from the specified HTTPS URL.
map file <path> Load a local offline map from a PMTiles file.
watch Continuously display live information from connected devices. Press Ctrl+C to stop.
exec <script-file> Execute commands from a script file. Empty lines and lines beginning with # are ignored.
