Spectrum

The spectrum tab shows spectra as a count histograms, retrieved from a connected detector or loaded from a compatible file. It can show several spectra combined in one plot or in separate tabs within the spectrum tab, see . This can be changed under Options -> Tabbed-/Combined Spectrum View (then selecting the files or data to be shown).

Background spectra can be viewed as: Background overlay and background subtract or not at all: No background. Background overlay shows the background spectrum overlaid on top of the main (foreground) spectrum. Background subtract subtracts the background, channel by channel, from the foreground spectrum. Note that this is a hard background subtraction and will thus effect spectrum ROI calculations. Both Background overlay and Background subtract are limited to show count rate values.

Regions of interest (ROI) are sub regions of the spectrum bounded in energy and are useful in the analysis of spectrum peaks. Spectrum peaks can in most cases be approximated with a Gaussian function, knowing the function parameters is useful for many analyses. LuRaCs provides a method for fitting Gaussian functions to peaks inside ROIs and do so by default. These fits are required by other tools in the application. However, ROIs can also be configured to not perform fits. In these cases, only the total counts within each ROI are calculated.

ROI Editor options
Field Description
ROI Name An alias for the ROI used for display purposes and easier identification.
Lower Bound The lower energy bound of the ROI.
Upper Bound The upper energy bound of the ROI.
Peak Function The type of function fitted to the peak. Options are: Guassian, None
Background Type of function used as peak background. Options are: None, Linear, Quadratic
Edge Channels The number of channels inside the ROI from the upper and lower bounds of the ROI used to fit the background.
Nuclide Assign a nuclide from the reference library to the ROI. Used for calculations by other tools.
Photopeak Choose the specific photon emission associated with the peak in the ROI. Options are based on the chosen nuclide.
Auto Match Nuclide Attempt to automatically find the nuclide and emission of the peak. If any nuclides are checked in the Isotopics-tab, see section [sec:isotopics], the match is limited to these. Blind matches are often unreliable.
Allow Merging Allow the ROI to merge with other ROIs with merging allowed.
Movable If the ROI can be moved or its bounds adjusted by using the mouse.
Use Poission Weights Apply a 1/σ weight to the optimisation to force the peak to emulate a Poission distribution.
