Spectrogram

A spectrogram allows acquisition of data time-series. A spectrogram stores data with specified time intervals and can be displayed in a waterfall plot. It is also the function LuRaCs utilise for mobile measurements. If a GPS is connected, the geolocation data is automatically stored in the spectrogram. These measurements can be visualised on the embedded Map (or an online map).

  1. Opens a dialog for starting a new spectrogram.

  2. Close the viewed spectrogram.

  3. Shortcut to the Data Library Spectrogram page, see section [sec:data_store].

  4. Toggle the currently loaded spectrograms. Status is shown to the left as [ACTIVE], [LOADED] or [PAUSED].

  5. Pause or Resume data collection, requires that the same detector used to collect the previous data is connected.

  6. Options menu, see

  7. Current information stored in the spectrogram and information about the Time Selector, if active.

  8. Count histogram. Shows either total accumulated spectrum when loading a previously acquired spectrogram, summed channel counts inside the Time Selector, if active, or counts in the latest row.

  9. ROI illustrated in the histogram, can be removed with Mouse-2.

  10. Waterfall diagram of the spectrogram.

  11. Time Selector to study the summed spectra within a specific time interval. Can be toggled in the options menu (6.).

  12. Data break line, illustrates that the time between measured points exceeds the Time Interval. Can indicate a lost connection and thus caution should be taken to verify data integrity. Can be toggled in the options menu (6.).

  13. Y-axis displays the timestamps of when each row was measured.

  14. X-axis display spectrum energy, if calibrated.

  15. Color slider for the waterfall diagram. The color map can be changed by clicking Mouse-2 on the gradient bar.

The spectrogram format is based around an SQLite database, see section [sec:file_spectrogram] for further details on the format. The following data is stored for each time point in the spectrogram:

  • Timestamp.

  • Average count rate measured since the last time point.

  • Average dose rate measured since the last time point.

  • Device temperature at the time the data is stored.

  • Longitude at the time the data is stored, if a GPS is available.

  • Latitude at the time the data is stored, if a GPS is available.

  • Spectrum difference since the previous data point was stored, as compressed binary.

  • Meta data, stored as a utf-8 encoded and zlib compressed json-string. Examples of stored metadata include extended GPS data.

Exporting a spectrogram

is done trough the Data Library, accessed via the Load-button (2.).

Description of the possible operations in the spectrogram options menu
Field Description
Pause Visual Updates Stop the view spectrogram from updating while the measurement is still on going in the background. This does not stop the recording of the spectrogram.
Time Selector Add a selected ROI in the spectrogram (11.) that can indicate the specific time interval, as opposed to all other ROIs that have energy bounds, and show the sum over time of the channels in the top count histogram (8.).
Selection to Spectrum Export the data within a selected time interval to the Data Library as a spectrum.
Accumulated to Spectrum Export the accumulated counts to the Data Library as a spectrum.
Show Break Lines If the red lines (12.) indicating if the interval between two rows exceed the specified save interval should be shown.
Keep Aspect Ratio If the pixels in the spectrogram should always be square. For detectors with many channels it can be useful to turn this off. If this option is off the pixels in the spectrogram may not align with the corresponding bar in the count histogram.
Load ROIs Shortcut to the ROI tab of the Data Library.
Import ROIs Load ROIs from a LuRaCs XML-file.
Clear ROIs Remove all spectrogram ROIs
