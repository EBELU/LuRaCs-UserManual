Map

Loading a map enables viewing of geographic measurements made with a spectrogram and a GPS. Maps can be loaded from online API requiring an internet connection or loaded from a .pmtiles-file for offline use. Compatible APIs and files are offered by several sources, the software QGis offers support for exporting .pmtiles from other formats using plugins.

The map is rendered using Qt’s web engine, making it a powerful but resource demanding tool. Using offline maps can require a lot of system memory since the server needs to cache tiles for a smooth view. It is therefore recommended to use a system with enough memory when this option is applied. However, both the map and datapoints are rendered using GPU acceleration with WebGL, allowing for 10 000s of points to be displayed without excessive stress on the system. For reference, a Raspberry Pi 5 with 8 GB of RAM can render a 1.4 GB map file without any stutter, total memory usage was approximately 2 GB.

  9. Current GPS position, always displayed as a white and blue circle.

Load a map

is done from Map Options -> Load Online/Offline Map. An offline map takes the form of a .pmltiles file. By choosing this option prompts the selection of such a file. Choosing to load an online map prompts the user to enter a URL, to a tile serving API, possibly including an API key. The checkbox allows for saving the most recently used URL. If a personal API key is used, be aware that URLs are saved unencrypted.
