Detector Connection & Control

Connecting detectors using the GUI is facilitated through a dialog for each type of connection, they are found under Detector -> Connect Bluetooth/USB/Network. Connecting via Bluetooth or USB requires the application to scan for available devices. The serial number of the connected devices are then displayed, allowing the user to select the appropriate device. Connecting to network devices requires knowing the IP address and type of the device. Connecting to network detectors have the unique option to use the detector as a GPS. At the moment, this is primarily intended for the Ortec Detective X which has a built in GPS. When connecting to serial GPS devices the application scans serial ports and lists suggestions. The port can also be entered manually. The baud rate is typically 4800 but a selection of other common rates are also available.
