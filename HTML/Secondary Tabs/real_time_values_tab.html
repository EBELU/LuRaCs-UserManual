Real Time Values

Plots the values sampled for a detector in real time. Not all detectors provide both Count Rate and Dose Rate, in such cases the detector is still registered to the plot but noting is shown in LuRaCs spectrum view/tab. The y-axes can be changed from linear to logarithmic scale clicking Mouse-2 on the plot Plot Options -> Transforms -> Log Y.

  1. Count Rate plot.

  2. Dose Rate plot, y-axis is always in .

  3. Latest values sampled from the corresponding detector.
