Spectrogram ROIs

Spectrum ROIs apply a curve fitting whereas Spectrogram ROIs do not. When applying a ROI to a spectrogram it sums the counts from all the channels within its bounds and do so for every row in the spectrogram. The results are displayed in count rate, as the number of counts are normalised to the save interval. This makes it easier to compare spectrograms recorded with different save intervals.

  1. Plots of two spectrogram ROIs evaluated on two separate spectrograms.

  2. Calculation ROI

  3. Button for removing the calculation ROI

  4. Settings for the first spectrogram in the calculation ROI. The first combobox lists loaded spectrograms and the second selects the data, total count rate or count rate from a ROI.

  5. Mathematical operations for comparing the ROI values are: +, - or /.

  6. Settings for the second spectrogram in the calculation ROI. These setting are the same as for the first (4.).

  7. ROI names. Calculation ROIs currently only have a tag containing a serial number on the form CAL_X. Currently, they can not be renamed.

  8. ROI data in text form. Shown is the latest value and (mean+-std) calculated from the data shown in the plot.

During mobile measurements LuRaCs offers the selection to monitor several ROIs simultaneously. For this e a ’Compact View’ can be used. This is enabled under View -> Spectrogram ROis -> Compact View. This function strips all GUI elements from the plots, except the y-ticks and the plot itself.

Calculation ROIs are plots calculated from the results of other ROIs. These perform element wise operations and do not account for differences in measurement parameters. Element 0 from ROI 0 is combined with Element 0 of ROI 1, regardless of measurement date or spectrogram save interval.
