Spectrum ROIs

  1. Remove all loaded ROIs from all spectra.

  2. Debug view of all data contained in the loaded ROIs.

  3. Apply time normalisation to the ROI data.

  4. Export the acquired and calculated data, including live time, of each ROI to a CSV-file.

  5. Save ROI references to the Data Library, see section [sec:data_store], for later access. These ROI references save the settings of the ROI (bounds, emission, name, fit type, etc.) but not the ROI data.

  6. Icon to display if the spectrum is background subtracted. Background subtraction effects the results of the ROI calculations.
