Spectrum Info

Displays information about loaded spectra, both from files (which ones, write out) and detectors memory.

Description of the columns in the Spectrum Info tab
Column Description
Column 0 Color button allowing for changing the color of the displayed. Options button marked with ’...’, see .
Spectrum The name of the spectrum or connected detector. A spectrum retrieved from a detector is automatically given the same name as the detector, this can not be changed unless the spectrum is saved or exported.
Type Foreground or Background, these share the same name in the ’Spectrum’-column for the same spectrum. This division exists because a spectrum can contain both foreground and background that have different measurement times and total counts.
Live Time The live time (h:min:s) of the measurement, accounting for dead time.
Real Time The real time (h:min:s) of the measurement.
Calibrated True or False, if an energy calibration is detected and applied.
Instrument Which instrument is assigned to the spectrum, see section [sec:definitions]
Description of the options menu opened by the button marked ’...’ on each row. The type ’Background’s are limited to only the ’Remove’ option.
Field Description
Save Save the spectrum to the Data Library.
Export Export the spectrum to a standalone file in the following formats: XML, CSV, xlsx.
Hide/Show Toggle visibility of the spectrum in the spectrum view. ROIs are not applied to hidden spectra.
Edit Edit properties of the spectrum, see .
Remove Spectrum Remove the spectrum and disconnect a detector associated with the spectrum.
