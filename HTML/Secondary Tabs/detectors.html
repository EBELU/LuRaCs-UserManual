Detectors

Information and status of connected detectors are displayed in this tab.

Description of the columns in the Detectors tab
Column Description
Column 0 Options button marked with ’...’, see .
Detector The name of the detector.
Temperature The temperature reading from the detector in ∘C. Most detectors report the ambient temperature but some, like the Detective X, report the cooled crystal temperature, as seen in .
Battery The current battery level in %.
Charging Indicate if the detector is connected to a power source.
Voltage The actual voltage reported of the detector in V.
Status

Detector state reported as one of the following options:

  • UNINITIALIZED - Detector client created but not started.

  • CONNECTING - The detector is starting.

  • CONNECTED - The detector is connected and running. Default for normal detector function.

  • CONNECTION_FAILED - Detector start failed. Check System Log.

  • CONNECTION_LOST - Connection was lost after a successful start. Not universally implemented.

  • STOPPING - The detector has received and acknowledged the command to stop.

  • STOPPED - The detector has successfully stopped.

  • ERROR - An error occurred while connected and the detector is no longer functioning as expected.
Type Type of detector by the name defined in the detector client.
Connection How the detector is connected. Can be BLE, USB or NETWORK.
Description of the options menu in the detector tab, opened with the button marked ’...’ in the table.
Field Description
Disconnect Sends a stop signal to the detector.
Reset Spectrum Signals to the selected detector to clear its spectrum.
Start Acquisition Signals to the selected detector to start spectrum acquisition.
Stop Acquisition Signals to the selected detector to stop spectrum acquisition.
Make Instrument Shortcut for creating a Unique Instrument for the detector based on a Generic Instrument and save the current calibration of the connected spectrum. Useful for detectors that do not Library their own energy calibration.
Settings Opens the detector settings dialog, see and .

  1. Unique Instrument from the library to pull settings from.

  2. Interact with the detector. Pull Calibration will request a calibration from the detector set in the coefficients buffer, not possible for all detectors. Push Calibration will attempt to set the calibration of the detector, not possible for all detectors.

  3. Pull the calibration coefficients from the spectrum connected to the detector and set in the coefficients buffer.

  4. Pull the calibration coefficients from the instrument set in (1.) and set in the coefficients buffer
