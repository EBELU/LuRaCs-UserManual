Settings

The settings are divided into Settings that contain basic and cosmetic settings, and Advanced Settings containing settings that ordinary users rarely need to interact with.

Application settings.
Setting Description
Table  – continued from previous page
Setting Description
Theme Select the visual theme used by the application interface and plots.
Plot Colour Scheme Select the color scheme used when automatically assigning colors to plotted spectra. Options are MatplotLib, LibreOffice and Catppuccin
Spectrum Draw Style Select how spectra are rendered. Available options are Pen, Brush, and Pen + Brush.
Font Size Set the application font size in points.
Spectrum Plot xMax Set the maximum energy displayed on spectrum plots, in keV.
Verbose Calculation Logging Enable additional logging during calculations. This can be useful when diagnosing calculation or processing problems.
Load ROIs on import Automatically load regions of interest when importing a spectrum from a file.
Load instrument on import Automatically load instrument information when importing a spectrum from a file.
Load calibration from instrument Load the energy calibration associated with the instrument when importing data from the Data Store or from a file.
Advanced application settings.
Setting Description
Table  – continued from previous page
Setting Description
Update Loop Delay Set the delay between iterations of the device monitoring and update loop, in seconds.
Spectrum Update Delay Set the delay between spectrum updates during live acquisition, in seconds.
GUI Scan Length Set the duration of Bluetooth Low Energy scans initiated through the graphical user interface, in seconds.
Headless Scan Length Set the duration of Bluetooth Low Energy scans when no the scan is not tracked in the GUI, in seconds.
Optimizer Max Iter Set the maximum number of iterations allowed by the optimizer.
Optimizer Tolerance Set the convergence tolerance used by the optimizer.
Use Chi2 Weight Enable χ2 weighting during optimization.
Log Exceptions Enable logging of unhandled exceptions.
Write logs to file Enable writing log messages to the application log file.
Write logs to console Enable writing log messages to the terminal or console.
Headless Log Buffer Length Set the maximum number of log entries retained in the in-memory log buffer. Changes to this setting require an application restart.
Spectrogram View Buffer Set the number of recent spectrogram data points retained for display.
Save extra GPS data Enable saving additional GPS information with map-related data.
