Deconvolution

This tool does more than simply reducing the effect of energy resolution but will still be referred to as a deconvolution operation. Deconvolution in this sense is more similar to reconstruction as in image reconstruction in nuclear medicine, it employs the ML-EM algorithm. By using a detector response matrix, most simply acquired using Monte Carlo-simulations, the effects of the detector resolution, scattering in the detector and other effects can be reduced. Description of the deconvolution window.
Field Description
Algorithm Which algorithm should be used. Options are ML-EM (use this) and Generalized Richardson-Lucy.
Iterations The number of iterations the algorithm should run.
(ML-EM) Response Matrix The path to a .npz file containing the detector response matrix to be used.
Instrument Instrument providing information for the algorithm. For instance, Generalized Richardson-Lucy is based on the resolution saved in the instrument.
Spectrum Which spectrum should the operation be executed on.
