Calibration

Calibration is the operation of setting the energy each channel corresponds to.

  1. Which spectrum should be used for the calibration. For each calibration, data from only one spectrum is allowed.

  2. Add a calibration point, that is not associated with a ROI. Measured and Reference energies must be set manually.

  3. Current calibration points detected and their corresponding information. When unchecking a row it will be ignored in the calculation.

  4. Polynomial degree of the calibration function and the current coefficients. Coefficients can be changed manually but will be updated by pressing Calculate.

  5. The instrument used for acquiring the spectrum. This is fixed and can not be changed here, instead edit the spectrum before starting the calibration, see section 0.0.1.

  6. Plot showing the energy as a function of channels based on the latest calculated coefficients.

  7. Assign the coefficients to the Unique Instrument shown in (5.).

  8. Assign the new calibration coefficients and recalculate the x-axis for the spectrum selected in (1.), updating the view in the Spectrum-tab. Note, this will not change the calibration of an already started spectrogram.
