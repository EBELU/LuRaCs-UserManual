\section{Python Tools}
While LuRaCs is primarily a stand alone application it can also be used as a python module when installed with \texttt{pip} or from source, exposing a number of internal functions to make it easier to use its file formats.

\subsection{Parsing XML}
XML is the primary format for spectra, ROIs and instruments used by LuRaCs. The application parser is exposed through the \texttt{file\_io} module. The parser is a class that takes a filepath in the constructor and then exposes the parsed results through methods.
