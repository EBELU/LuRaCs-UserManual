\subsection{Top Tabs}

\subsubsection{Spectrum}
The spectrum view shows spectra as a count histogram, retrieved from a connected device or loaded from a file. It can show several spectra combined in one plot or separately. This can be changed under \texttt{Options $\rightarrow$ Tabbed / Combined Spectrum View}.

\subsubsection{Spectrogram}
A spectrogram allows time-series measurements to be conducted. A spectrogram stores data at specified time intervals and can be displayed in a waterfall plot.
