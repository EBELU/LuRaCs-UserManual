\subsection{Top Tabs}
\subsubsection{Spectrum}
The spectrum view shows spectra as a count histograms, retrieved from a connected device or loaded from a file. It can show several spectra combined in one plot or separately. This can be changed under \texttt{Options $\rightarrow$ Tabbed / Combined Spectrum View}.


\subsubsection{Spectrogram}
A spectrogram allows time-series measurements to be conducted. A spectrogram stores data at specified time intervals and can be displayed in a waterfall plot.

The spectrogram format is based around an SQLite database, see section \ref{sec:file_spectrogram} for further details on the format. The following data is stored for each time point in the spectrogram:

\begin{itemize}
    \item Timestamp.
    \item Average count rate measured since the last time point.
    \item Average dose rate measured since the last time point.
    \item Device temperature at the time the data is written.
    \item Longitude at the time the data is written, if a GPS is available.
    \item Latitude at the time the data is written, if a GPS is available.
    \item Spectrum difference since the last written data point, stored as compressed binary.
    \item Meta data, stored as a utf-8 encoded and zlib compressed json-string. Examples of stored metadata include extended GPS data.
\end{itemize}



\subsubsection{Map}
Loading enables viewing of measurements made with a spectrogram and a GPS. Maps can be loaded from online API requiring an internet connection or loaded from a \textit{.mbiles}-file for offline use. Compatible APIs and files are offered by several vendors, the software \textit{QGis} offers great support for exporting \textit{.mbiles} from other formats.
